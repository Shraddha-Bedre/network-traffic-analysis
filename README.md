# Network Traffic Analysis

Network traffic analysis and PCAP investigation exercises performed using Wireshark for cybersecurity learning and research.

### Topics Covered

- PCAP traffic analysis
- Wireshark packet analysis
- Suspicious traffic investigation
- Malicious activity analysis
- Network protocol analysis
- hping3 and Wireshark based DoS simulation

### Practical Exercises

- Traffic Analysis Exercise: Easy as 123
- Traffic Analysis Exercise: Lumma in the Room-ah!
- Traffic Analysis Exercise: It's a Trap!
- Traffic Analysis Exercise: Download from Fake Software Site
- Traffic Analysis Exercise: Nemotodes
- DoS Attack Simulation using hping3 and Wireshark

### Purpose

Developed for cybersecurity learning and controlled lab practice only.

> All security testing and attack simulations were performed for educational purposes in authorized environments.
